# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [0.1.0] - Unreleased

First release: a port of the Go implementation
([github.com/victorcondackdev/cnab-go](https://github.com/victorcondackdev/cnab-go)) to .NET 8.

### Added

- `FixedWidth`: attribute-driven fixed-width codec (`[CnabField(start, length, format)]`
  with `Num`, `Alfa`, `Raw`, `Date`, `Money`, `Const`) with layout
  self-validation (gaps, overlaps, out-of-range positions, type mismatches,
  integer widths) compiled once and cached per type, trimming and AOT
  annotations, `Validate`/`Check`/`Width`/`Fields` introspection and
  `AsciiFolding` for accent folding.
- Exceptions: `CnabException` with a `CnabError` kind, and `CnabFieldException`
  (line, property, positions, value, reason, writer context),
  `CnabLineException`, `CnabLayoutException` and `RemessaException`, with
  messages identical to the Go implementation.
- `Cnab.Cnab240`: FEBRABAN CNAB 240 cobrança records (file and batch headers
  and trailers, segments P, Q, R, T, U), `RawSegment` passthrough, movement and
  espécie enums with Portuguese `Describe()`, and title/occurrence grouping.
- `Cnab.Cnab400`: generic CNAB 400 header/detail/trailer skeleton and an
  experimental Bradesco remessa detail layout.
- `CnabFile`: `Parse`/`Parse400` from `TextReader` or `Stream` (Latin-1) with
  structural validation and optional totals check, and layout detection.
- `CnabWriter`: CNAB 240 and 400 writing with regenerated counts, batch numbers
  and sequences; configurable line endings.
- `Cnab.Remessa`: fluent `RemessaBuilder` with CPF/CNPJ, CEP and amount validation.
- `Cnab.Reconciliation`: retorno-versus-expected reconciliation with explained
  differences and the same text summary as the Go implementation.
- `Money`: culture-invariant formatting and parsing of `long` cents.
- `samples/Cnab.Cli`: `inspect`, `validate` and `reconcile` commands with `--json`.
- Cross-language parity suite generated by running the Go implementation
  (`tools/vecgen`), a seeded robustness suite and BenchmarkDotNet benchmarks.
